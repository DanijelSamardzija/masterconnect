🔧 Unregister Service Worker

Ova stranica će:

  1. Unregister-ovati sve service workere
  2. Očistiti sav keš
  3. Primorati hard reload

Alternativa: Ručni hard reload

  • Windows/Linux: Ctrl + Shift + R ili Ctrl + F5
  • Mac: Cmd + Shift + R
  • Chrome DevTools: Otvori DevTools > desni klik na Refresh > Empty Cache and Hard Reload
