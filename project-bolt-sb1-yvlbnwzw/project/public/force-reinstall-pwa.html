🔄 Force PWA Reinstall

Rešavanje problema sa belim Navigation Bar-om

⚠️ VAŽNO: Zašto je ovo potrebno?

Android keširaje manifest.json fajl. Stari manifest ima staru theme_color vrednost. Bez kompletnog uninstall-a, nav bar će ostati beo.

1 Uninstall PWA aplikaciju

  1. Idi na Home Screen
  2. Drži dugo ikonu GigZone
  3. Odaberi Uninstall ili Remove
  4. Potvrdi brisanje

2 Clear Chrome Data

  1. Otvori Chrome browser
  2. Idi na sajt: handyman-service-pla-h96a.bolt.host
  3. Klikni na ikonicu za lock/info (levo od URL-a)
  4. Odaberi Site settings
  5. Scroll do Storage
  6. Klikni Clear data

3 Unregister Service Worker

4 Hard Refresh

5 Reinstall PWA

  1. Na sajtu, Chrome će ponovo prikazati "Install app" prompt
  2. Klikni Install
  3. Otvori instaliranu aplikaciju
  4. Proveri da li je navigation bar sada CRNI ⬛
✅ Checklist - Proveri sledeće:
  • Navigation bar (Back/Home) je crni u instaliranoj PWA
  • Status bar na vrhu je crni
  • Splash screen (loading) je crni
  • Aplikacija se otvara u standalone modu (bez Chrome UI-a)

🔍 Ako i dalje ne radi...

Na nekim Android/OneUI uređajima, navigation bar boja ne može uvek 100% da se kontroliše iz PWA ako:

  1. Uređaj koristi Gesture Navigation (umesto Button Navigation)
  2. System theme je Light Mode (Android forsira kontrast)
  3. Koristiš Samsung Internet umesto Chrome-a
  4. Instalirana verzija je "shortcut" a ne prava PWA

Preporuka: Koristi Chrome browser i proveri da je "Button Navigation" uključen u Android Settings → Display → Navigation bar.
